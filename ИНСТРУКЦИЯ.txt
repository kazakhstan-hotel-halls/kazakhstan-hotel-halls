САЙТ КОНФЕРЕНЦ-ЗАЛОВ ОТЕЛЯ «КАЗАХСТАН» — КАК ЗАПУСТИТЬ
==========================================================

В архиве:
  site/          — сам сайт (index.html и фотографии залов). Эту папку выкладываем в интернет.
  Code.gs        — скрипт для Google Таблицы (календарь и заявки).
  ИНСТРУКЦИЯ.txt — этот файл.

Как это работает:
  • Гость открывает сайт, видит залы, цены, меню и свободные даты, сайт сам считает стоимость.
  • Занятые даты вы отмечаете в Google Таблице (лист «Календарь») — сайт показывает их гостям.
  • Заявки гостей сами появляются в таблице (лист «Заявки») и, если хотите, приходят на почту.
  • Меняете статус заявки на «Предв. бронь» или «Подтверждена» — дата сама отмечается в календаре.

Понадобится только Google-аккаунт (Gmail). Время — около 15 минут.


ШАГ 1. СОЗДАЙТЕ ТАБЛИЦУ
-----------------------
1. Откройте https://sheets.new — создастся пустая Google Таблица.
2. Назовите её, например: «Залы — календарь и заявки».
3. Файл → Настройки:
     Региональные настройки: Казахстан (или Россия)
     Часовой пояс: (GMT+05:00) Almaty
   Нажмите «Сохранить настройки».


ШАГ 2. ВСТАВЬТЕ СКРИПТ
----------------------
1. В таблице: Расширения → Apps Script. Откроется редактор кода.
2. Удалите всё, что там написано, и вставьте целиком содержимое файла Code.gs
   (откройте его Блокнотом, Ctrl+A, Ctrl+C, затем в редакторе Ctrl+V).
3. По желанию: в строке  const NOTIFY_EMAIL = "";  впишите между кавычками почту,
   куда присылать новые заявки, например:  const NOTIFY_EMAIL = "sales@hotel.kz";
4. Нажмите значок дискеты (Сохранить).
5. Вверху в списке функций выберите  setup  и нажмите «Выполнить».
6. Google попросит разрешение:
     «Проверить разрешения» → выберите свой аккаунт →
     «Дополнительные настройки» → «Перейти на страницу проекта (небезопасно)» → «Разрешить».
   Это нормально: Google так предупреждает о любом своём скрипте, который вы написали сами.
7. Вернитесь в таблицу — появятся листы «Календарь» и «Заявки» с выпадающими списками.


ШАГ 3. ВКЛЮЧИТЕ СВЯЗЬ С САЙТОМ
------------------------------
1. В редакторе Apps Script справа вверху: «Начать развертывание» → «Новое развертывание».
2. Нажмите шестерёнку рядом с «Выберите тип» → «Веб-приложение».
3. Заполните:
     Описание:           сайт залов
     Запуск от имени:    Я (ваша почта)
     У кого есть доступ: Все
4. «Начать развертывание». Скопируйте «URL веб-приложения» — он заканчивается на /exec.


ШАГ 4. ВСТАВЬТЕ ССЫЛКУ В САЙТ
-----------------------------
1. Откройте файл site/index.html в Блокноте (Windows: правой кнопкой → Открыть с помощью → Блокнот;
   Mac: TextEdit, затем Формат → Сделать простым текстом).
2. Найдите (Ctrl+F):  ВСТАВЬТЕ_ССЫЛКУ_СЮДА
3. Замените эти слова на скопированную ссылку. Кавычки оставьте. Должно получиться так:
     const API_URL = "https://script.google.com/macros/s/AKfy.../exec";
4. Строкой ниже указан номер WhatsApp менеджера (77021221087). Если нужен другой — поменяйте, только цифры.
5. Сохраните файл.


ШАГ 5. ВЫЛОЖИТЕ САЙТ В ИНТЕРНЕТ
-------------------------------
1. Зарегистрируйтесь на https://app.netlify.com (бесплатно, можно через Google).
   Без аккаунта сайт удалится через некоторое время.
2. Откройте https://app.netlify.com/drop и перетащите мышкой ПАПКУ site в окно браузера.
3. Через несколько секунд появится ссылка на сайт, вида https://random-name-123.netlify.app
4. Красивое имя: Site configuration → Change site name → например  kazakhstan-halls
   → сайт станет https://kazakhstan-halls.netlify.app
5. Свой домен (например halls.hotelkazakhstan.kz): Domain management → Add a domain.
   Для этого понадобится IT-отдел или тот, кто управляет доменом отеля.


ПРОВЕРКА
--------
1. Откройте сайт, отправьте тестовую заявку на любую дату.
2. В таблице на листе «Заявки» должна появиться строка со статусом «Новая».
3. Поставьте ей статус «Предв. бронь» — на листе «Календарь» появится эта дата.
4. Обновите сайт — дата станет жёлтой (предварительная бронь). Тестовые строки потом удалите.


КАК ПОЛЬЗОВАТЬСЯ КАЖДЫЙ ДЕНЬ
----------------------------
• Занятую дату добавляйте строкой на лист «Календарь»: Дата | Зал | Статус.
  Статус «Занято» — красный на сайте, «Предварительная бронь» — жёлтый.
  Чтобы освободить дату — удалите строку целиком.
• Новые заявки — на листе «Заявки» (статус «Новая»). Меняйте статус в выпадающем списке:
    Предв. бронь  → дата в календаре станет «Предварительная бронь»
    Подтверждена  → дата станет «Занято»
    Отклонена     → отметка в календаре снимется (если её поставила эта заявка)
• Сайт подхватывает изменения при обновлении страницы (у открытых страниц — раз в 5 минут).


КАК ПОМЕНЯТЬ ЦЕНЫ ИЛИ МЕНЮ
--------------------------
Цены и меню записаны в файле site/index.html, в начале блока <script>:
  • HALLS — залы: аренда, оборудование, цены пакетов Standard/Premium, предоплата;
  • MENU  — кофе-брейки, обеды, ужины, гала-ужины: цена (net — без НДС) и состав;
  • VAT = 0.16 (НДС 16%) и DISCOUNT = 0.10 (скидка 10% для Grand Ballroom и Grand Palace).
Исправьте число, сохраните и выложите заново: на Netlify откройте сайт → Deploys →
перетащите папку site в поле «Drag and drop your site output folder here».
Ссылка сайта при этом не меняется.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
• На сайте написано «Календарь сейчас недоступен» — проверьте ссылку в index.html (шаг 4)
  и что в развертывании стоит доступ «Все» (шаг 3).
• Если меняли Code.gs — изменения не применятся, пока не обновите развертывание:
  «Начать развертывание» → «Управление развертываниями» → карандаш → Версия: «Новая версия» → «Начать развертывание».
  Ссылка при этом остаётся прежней.
• Если заявка не отправилась, сайт сам предложит гостю скопировать её или отправить в WhatsApp —
  заявка не потеряется.
